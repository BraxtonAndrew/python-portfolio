# Python Portfolio

Small Python projects covering file parsing, REST APIs, GUI programming, and security basics.

| Project | What it shows |
|---|---|
| [oil-price-analyzer](oil-price-analyzer/) | Streaming a 5M-line file, parsing, per-day min/max aggregation, CLI arguments |
| [bcrypt-password-demo](bcrypt-password-demo/) | Salted password hashing and verification with bcrypt |
| [swapi-planet-lookup](swapi-planet-lookup/) | Calling a paginated REST API, input validation, error handling |
| [password-generator-gui](password-generator-gui/) | Tkinter GUI that fetches data from a web API |

## Setup

Requires Python 3.9+.

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Each project folder has its own README with run instructions.
